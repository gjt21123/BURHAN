# BURHAN 0.2.0 — OSS preview

An early-stage source release for reproducing and improving independent verification of bounded coding-agent work. This is not a production security certification or a general-purpose proof system.

## Included

- Apache-2.0 license, notice, contributor/security/governance policies, structured issue/PR templates and maintainer documentation.
- Credential-free CI across Linux, macOS and Windows on Node 22 and 24; separate full Windows reference verification.
- Qualified positive/negative controls, fresh-workspace verification and local receipt-integrity demonstrations retained from the reference implementation.
- Safe local HTTP compiler/reset boundaries with 22 regression tests and nine production HTTP smoke checks.
- Correct Next.js generated-type handling and clean working-tree enforcement.
- All-dependency npm vulnerability auditing, CodeQL and explicit dependency-graph availability reporting.
- Honest Codex for OSS application drafts and a scoped validation record.

## Compatibility and behavior changes

Use Node.js 22 or 24. The web stack is Next.js 16.3.5 and React 19.3.0; tests use Vitest 4.1.11. The full reference verification flow remains Windows-native.

The UI binds to `127.0.0.1`. Live HTTP compilation now requires `BURHAN_ENABLE_LIVE_COMPILER=1` plus a locally configured provider key in `apps/web/.env.local`. Without explicit opt-in, it returns `LIVE_COMPILER_DISABLED` and makes no provider call. Malformed, oversized, cross-origin or concurrent requests receive controlled errors.

## Evidence and limitations

The release attaches a source archive, SHA-256 checksum and `validation.json` identifying the exact tested commit and CI/CodeQL runs. Checksums and workflow links establish artifact identity and execution provenance, not independent assurance or SLSA certification.

Historical live Codex rejection and deterministic repair demonstrations remain separately labeled. No new live model run, external adopter, npm publication, formal proof or sandbox support is claimed.
