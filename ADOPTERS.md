# BURHAN Adopters

BURHAN is an early open-source project. This file is intentionally evidence-based: it does not claim adoption that has not been publicly confirmed.

If you use BURHAN in a project, CI workflow, internal evaluation, research prototype, or coding-agent workflow and are comfortable being listed, open a pull request with:

## Why this exists

Public, opt-in adopter references help maintainers understand real workflows, prioritize compatibility work, and avoid substituting stars or download counts for meaningful usage.

Anonymous usage reports are also useful. Open an issue without confidential details if you cannot be listed publicly.
